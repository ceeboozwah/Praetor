## Headline finding — contamination, not failure

Claude adapted `programs/wordfreq.lang`, which supplied the three
highest-signal discoveries the task was designed to force:
`StrMap` insert/`get_mut`, the `if true { }` borrow-shortening
idiom, and the `slurp_r` + `Result`/`?` read path.

So the run demonstrated **imitation-from-examples is strong** but
did **not** measure cold semantic discovery. Participant quote:
"`programs/wordfreq.lang` was the biggest help." Examples are
currently doing more teaching than the docs — a real onboarding
strength and a test-design leak.
