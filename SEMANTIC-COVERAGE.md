# SEMANTIC-COVERAGE — lab rules vs production compiler

Two corpora, two correctness dimensions. The `.mml` oracle corpus proves
a semantic rule; the `.lang` native corpus proves the real compiler both
enforces it (negative tests die before LLVM) and generates correct code
(positive tests run to `@exit`).
